# CRUD Operation - MERN Stack

A simple CRUD (Create, Read, Update, Delete) application built using the MERN stack.

## Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- Axios
- CORS

## Features

- Add a new user
- View all users
- Update user details
- Delete a user
- Store data in MongoDB

Installation

Clone the repository:
git clone https://github.com/kundan09431/Crud_Operation.git

Go to the project folder:
cd Crud_Operation

Backend
cd server
npm install
npm start

Frontend

Open another terminal:
cd client
npm install
npm start

Environment Variables

Create a .env file inside the server folder:

PORT=4000
MONGOURL=your_mongodb_connection_string
